# John Nwaigbo — Professional Portfolio
No build step required.

## Add a new project
Edit `projects.js`: copy one project object, change the fields, and commit. The website generates the project card and filter automatically.

## GitHub Pages
1. Create a public repository named `john-nwaigbo-portfolio`.
2. Upload the CONTENTS of this folder to the repository root.
3. Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/(root)` → Save.
5. Use the URL GitHub gives you.
